What it does

Built to grow on X, on autopilot.

Not a simple macro or script. X Automation Bot is a full reply engine with model fallback, quality gates and safety systems working together every run.

01

AI Reply Engine

The bot scans your home feed on x.com, understands each post, and writes a short, natural reply in context — no copy-paste templates, no repetitive spam text. Every reply is generated fresh for that post.

02

Multi-Model Fallback

If one AI model is busy, limited or returns a bad output, the engine automatically falls through to the next model — Gemini 3.7 Flash first, then 3.8, 3.6, 3.5 Flash Lite and 2.5 Flash Lite, with Groq GPT-OSS 20B → 120B on the Groq side. A failed model never stops your run.

03

Quality Gates

Replies are capped at 270 characters, filtered for degenerate or garbled output, and passed through a pre-submit gate — the typed reply is re-checked once before posting, and skipped if it doesn't match what the AI wrote.

04

Smart Reply Limit

You decide how far a run goes: set a limit from 1 to 100 posts per session. The bot works feed-only, counts every post, and stops cleanly with a “Done — N/M posts” status when the run finishes.

05

Draft Guard + Watchdog

A background Draft Guard and an alarm-based cycle watchdog keep long runs stable — if a cycle stalls, the watchdog restarts it, and the editor is polled smoothly so replies are typed and submitted reliably.

06

Built-In Activation Codes

No server, no admin panel — the activation codes live inside the extension itself. Each code runs for 7 days from its first use on a device; when it expires, you simply enter a fresh code and keep going.

Under the hood

The advanced system.

Three layers work together inside Chrome — a page engine on X, a background brain, and a verification layer — so the bot keeps running even when a model, a post, or a cycle fails.

Layer 1 · On the page

Feed Engine

Runs directly on x.com/home and handles everything you would do by hand — only faster and consistently.

  • Feed-only scanning — profiles and other pages are ignored
  • Human-style bot cursor that moves, hovers and clicks like a person
  • Smooth editor polling — waits until the reply box is truly ready
  • Skip reasons logged — you always see why a post was skipped
Layer 2 · In the background

Cycle Brain

A background service worker keeps the automation alive across the whole session.

  • Chrome alarms cycle drives run after run without babysitting
  • Watchdog detects a stuck cycle and restarts it automatically
  • On-demand injection with a double-inject guard — the engine loads once, cleanly
  • Token tuning — Groq runs at 200 max tokens with low reasoning effort, so replies finish fast and complete
Layer 3 · AI + Access

Models & Licensing

Your own API key powers the AI, and built-in activation codes protect your plan — no license server involved.

  • Gemini chain: 3.7 Flash → 3.8 → 3.6 → 3.5 Flash Lite → 2.5 Flash Lite
  • Groq chain: GPT-OSS 20B → GPT-OSS 120B
  • Your API key stays on your device — bring your own Gemini or Groq key
  • Codes are built into the extension — checked on your device, no server needed; each code runs 7 days from first use, then a fresh code continues your access
